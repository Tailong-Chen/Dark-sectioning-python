# Notice

This Python implementation is derived from the MATLAB workflow in this repository,
especially `MATLAB_Code/Dark.m` and `MATLAB_Code/helpfunctions/*.m`.

The original project README states that Dark-sectioning is the official code for
"Dark-based Optical Sectioning assists Background Removal in Fluorescence
Microscopy" and that the authors claim an Apache license for Dark-sectioning.

Original authors named by the upstream README:

- Ruijie Cao
- Peng Xi
- Peking University

The Python port preserves the algorithmic provenance and keeps `MATLAB_Code/Dark.m`
as the sole v1 compatibility target. It does not claim behavioral compatibility
with `MATLAB_Simplified_Fun`, the MATLAB App, or the Fiji/ImageJ plugin.
